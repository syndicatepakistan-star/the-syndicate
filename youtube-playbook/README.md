# YouTube High-CPM Playbook — Software / Tech Channel

Actionable deliverables from the High-CPM Country & Niche research. **Creator location does not set CPM; viewer country does.** Pakistani AdSense still receives payouts; US/UK/AU viewers raise RPM.

## Channel positioning (locked)

- **One English personal channel:** Modern software / AI tools for builders & freelancers  
- **Primary markets:** USA + UK (CPM); UAE secondary  
- **Mix:** 70% SaaS/AI tutorials & comparisons · 20% build-in-public · 10% fintech-app explainers  
- **Cadence:** 1 long-form weekly + 3–5 Shorts as clips  
- **6-month success metric:** Rising % watch time from US/UK/AU/CA — not raw views alone

## Top 10 high-paying viewer countries (industry estimates)

Australia · United States · Switzerland · Norway · New Zealand · Canada · United Kingdom · Germany · Denmark/Ireland/Sweden · Netherlands/Singapore/UAE  

Tier-1 views can earn ~10–50× more than the same views from Pakistan/India. Numbers are ranges — replace with your Studio data via file 01.

## Five niches

1. B2B SaaS / AI work tools  
2. Developer / cloud / DevOps tools  
3. Fintech + money apps (software lens)  
4. No-code automation / AI agents for business  
5. Cybersecurity / privacy / compliance tools  

## Quick start

1. Pick title #1–4 from `02-niche-keyword-titles.md`.  
2. Schedule in Studio for **Wednesday 3:00 PM Eastern** (`03-upload-schedule.md`).  
3. After views/monetization, log geography and RPM (`01-analytics-validation.md`).
